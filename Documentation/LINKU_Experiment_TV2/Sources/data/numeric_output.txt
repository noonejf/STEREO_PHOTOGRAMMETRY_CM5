3. Uncollimated source: falloff across object depth
---------------------------------------------------
  non-uniformity NU = (Emax-Emin)/(Emax+Emin), IEC 60904-9 definition
  minimum throw D for a target NU, as a multiple of object depth dz:
    NU <=    2 % (class A) -> D >=  49.5 * dz
    NU <=    5 % (class B) -> D >=  19.5 * dz
    NU <=   10 % (class C) -> D >=   9.5 * dz
  NU produced by a given throw and depth:
    D =  3 m, dz = 0.5 m -> Emin/Emax = 0.735, NU =  15.3 %
    D =  5 m, dz = 0.5 m -> Emin/Emax = 0.826, NU =   9.5 %
    D = 10 m, dz = 0.5 m -> Emin/Emax = 0.907, NU =   4.9 %
    D =  5 m, dz = 1.0 m -> Emin/Emax = 0.694, NU =  18.0 %
    D = 10 m, dz = 1.0 m -> Emin/Emax = 0.826, NU =   9.5 %
